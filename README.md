# Interview AI Assistant MVP

Telegram AI-assistant for interview preparation.

## Stack
- Python 3.12+
- aiogram 3.x
- OpenAI API
- SQLite
- CSV Knowledge Base

## Current stage
Stage 1: Telegram bot skeleton + FSM. OpenAI and database integrations are intentionally not implemented yet.

## Run
1. Create `.env` from `.env.example`
2. Install dependencies: `pip install -r requirements.txt`
3. Run: `python -m app.main`
