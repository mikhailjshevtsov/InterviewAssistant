# Как адаптировать ассистента под новую профессию

Ассистент не привязан к конкретной профессии в коде: профессии, вопросы, STAR-примеры и чек-листы задаются CSV-файлами в `knowledge_base/`, а поведение модели — текстовыми промптами в `app/prompts/`. Анализ вакансии, генерация вопросов, разбор ответов и итоговый отчёт работают для любой вакансии; база знаний только повышает качество и релевантность вопросов.

Подробный формат файлов — в [KNOWLEDGE_BASE_GUIDE.md](KNOWLEDGE_BASE_GUIDE.md).

## Шаги

1. **Соберите материалы.** 5–10 реальных вакансий профессии: названия позиций, навыки, темы собеседований, типичные поведенческие вопросы.
2. **Зарегистрируйте профессию** в `knowledge_base/professions.csv`: код (латиница, `snake_case`), название для пользователя и псевдонимы из названий вакансий (русские и английские, основы слов).
3. **Добавьте вопросы** в `questions.csv`: не меньше 3 вопросов каждой категории (`technical`, `behavioral`, `situational`, `experience`); `star_required=true` для поведенческих вопросов и вопросов об опыте; ключевые слова — навыки из вакансий.
4. **Добавьте STAR-примеры** в `star_examples.csv`: не меньше 3 вымышленных примеров для поведенческих вопросов и вопросов об опыте, с измеримым результатом.
5. **Добавьте пункты чек-листов** в `checklists.csv` с кодом профессии, если профессии нужно что-то особое (портфолио, тестовое задание, демо). Общие пункты (`general`) уже есть.
6. **Проверьте данные:** `python -m app.knowledge.validate`.
7. **Запустите тесты:** `python -m pytest`.
8. **Проверьте вживую:** перезапустите бота (`python -m app.main`), пришлите вакансию новой профессии, сформируйте вопросы, ответьте на STAR-вопрос и откройте «📋 Чек-листы».
9. **Закоммитьте** CSV-файлы.

Пример готового набора строк для профессии «UX Researcher» есть в [KNOWLEDGE_BASE_GUIDE.md](KNOWLEDGE_BASE_GUIDE.md#пример-новая-профессия-ux-researcher).

## Что можно менять без Python

| Что | Где |
|---|---|
| Новая профессия и распознавание её вакансий | `knowledge_base/professions.csv` |
| Вопросы, их сложность, категория, STAR, ключевые слова | `knowledge_base/questions.csv` |
| Образцы STAR-ответов | `knowledge_base/star_examples.csv` |
| Пункты чек-листов, их приоритет, профессиональные пункты | `knowledge_base/checklists.csv` |
| Правила анализа вакансии, генерации вопросов, оценки ответа и итогового отчёта (тон, критерии, число вопросов, язык) без изменения полей ответа | `app/prompts/vacancy_analysis.txt`, `questions.txt`, `answer_analysis.txt`, `session_summary.txt` (`system.txt` не используется) |
| Модель OpenAI, таймаут | `.env` (`OPENAI_MODEL` и другие параметры из `.env.example`) |

После изменений нужен перезапуск бота: CSV и промпты читаются при старте и кэшируются. Строки про untrusted data в промптах удалять нельзя (это проверяют тесты).

## Что требует изменения Python

| Изменение | Что править |
|---|---|
| Новая категория вопросов (кроме `technical`, `behavioral`, `situational`, `experience`) | `QuestionCategory` в `app/schemas/question.py`, промпты, форматтеры, тесты |
| Новая категория чек-листов | `ChecklistCategory` в `app/schemas/knowledge.py`, `CHECKLIST_CATEGORY_LABELS` в `app/bot/formatters.py`, тесты |
| Новые колонки в CSV | DTO в `app/schemas/knowledge.py`, парсер и `*_COLUMNS` в `app/knowledge/csv_repository.py`, валидатор `app/knowledge/validate.py` |
| Новые поля в ответе модели (например, отдельная оценка soft skills) | Pydantic-модель в `app/schemas/`, промпт, форматтер ответа, при необходимости БД |
| Другой алгоритм отбора (веса, лимиты, число STAR-примеров) | константы в `app/services/knowledge_service.py` |
| Другие сценарии Telegram, кнопки, тексты интерфейса | `app/bot/` (handlers, keyboards, formatters, texts) |
| Другой язык интерфейса бота | тексты в `app/bot/`; CSV и промпты — на новом языке |
| Хранение базы знаний не в CSV (Google Sheets API, БД, vector search) | новый репозиторий с тем же интерфейсом, что у `CsvKnowledgeRepository`; сейчас не реализовано |

## Проверочный список

- [ ] Профессия есть в `professions.csv`, псевдонимы покрывают реальные названия вакансий.
- [ ] По 3+ вопроса каждой категории.
- [ ] 3+ STAR-примера без реальных компаний и персональных данных.
- [ ] `python -m app.knowledge.validate` — без ошибок.
- [ ] `python -m pytest` — все тесты зелёные.
- [ ] Ручная проверка в Telegram: вопросы относятся к профессии, разбор STAR-ответа не содержит фактов из примеров.
